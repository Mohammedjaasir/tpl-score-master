# TPL Cricket Live Scoring Web Application

This repository contains the official TPL 2026 cricket live scoring and match tracking web application.

## Core Stack
- **Framework**: TanStack Start + React 19 + TypeScript
- **Styling**: Tailwind CSS v4 + Vanilla CSS tokens
- **Routing**: TanStack Router (file-based)
- **Engine**: Event-based pure-functional cricket scoring engine
- **State**: localStorage persistence with repository pattern abstraction
